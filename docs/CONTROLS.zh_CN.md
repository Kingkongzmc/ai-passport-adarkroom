# 三键操作体验设计 — 《小黑屋》ESP32 完整重制

> 上游文档:[../DESIGN.zh_CN.md](../DESIGN.zh_CN.md) §0。硬件事实:仅 上/下/确定
> 三键,共用一个 ADC 引脚(无组合键、无同按);每键支持
> PRESS / CLICK / DOUBLE / LONG 四种手势;电源键不可编程。
>
> **本文档以当前固件实装为准**(v0.2,2026-09-24);设计稿中的构想若尚未
> 实装,以"〔规划〕"标注。进度差账见
> [IMPLEMENTATION_STATUS.zh_CN.md](IMPLEMENTATION_STATUS.zh_CN.md)。

## 1. 设计原则

1. **一个上下文,一个焦点**:任何时刻屏幕上有且只有一个高亮焦点
   (金色文字 + 行首 ">"),上/下只移动焦点,确定只作用于焦点。
2. **手势含义全局一致**(下表),任何页面不例外:
   | 手势 | 含义(实装) |
   | --- | --- |
   | 上 / 下(单击) | 焦点上移 / 下移(循环;**禁用行自动跳过**) |
   | 确定单击 | 进入/执行焦点项 |
   | 确定长按 | 返回上一级(例外见 §3;危险操作 = 打开确认弹窗) |
   | 上 / 下长按 | 仅村庄人数调节模式:±5;其余页面无动作 |
   | 确定双击 | 〔规划〕快捷动作(未实装) |
3. **方向不用手势硬凑**:荒野/房间导航采用列表式(方位写在文字里)。
4. **反馈即到**:每次按键必有可见反馈(焦点移动/日志/弹窗)。
5. **防误触**:危险操作(重开本局/全部卖出)必须经过确认弹窗;
   事件/战斗/确认页禁用长按返回,必须显式选择。
6. **按键节流**:开机 1.5s 防抖;每次渲染后 60ms 静默期丢弃幽灵按键。

## 2. 焦点模型(实装)

- 焦点样式:金色文字 + 行首箭头列(固定宽度,切换零位移);不画边框。
- **tab 导航**(主页顶栏 小屋/村庄/荒野/≡):动作区顶行按 上 进入页签区,
  光标为完整边框(与"所在页"的金色下划线是两个独立状态);上键在**启用的
  tab** 间循环(未启用直接跳过:村庄需有人、荒野未开放),下键回动作区,
  确定=切页。
- **禁用行跳过**:列表中锁定/资源不足的行灰显但光标不停留
  (建造:不可建造;村庄:锁定的职业;贸易:未建贸易站/存货不足);
  进页时焦点直接落在首个可用行;整页全禁用则焦点停在"返回"。
- 主页动作行 3~4 条(随陷阱建造增减),冷却中的动作显示暗色进度条,
  从右端向左收缩,期间按确定会得到"还在冷却"的提示而非误触发。

## 3. 各页面按键映射(实装)

| 页面 | 焦点行为 | 确定单击 | 确定长按 |
| --- | --- | --- | --- |
| 主页·标题 | — | 进入主页 | — |
| 主页·动作区 | 动作按钮列表 | 执行(收集/点火添柴/建造…) | — |
| 主页·页签区 | 启用的 tab | 切换页面 | — |
| 建造页 | 建筑列表(**不可建的行跳过**) | 建造/升级 | 返回主页 |
| 村庄页 | 职业列表 | 伐木工/猎人 → 进入人数调节;采集者 → 提示;锁定职业 → 提示 | **无**(见下) |
| 地图页 | 目的地列表 | 移动(东→废村/西→小屋已通) | 返回主页 |
| 房间页(废村) | 房间动作列表 | 〔规划 M4〕 | 返回地图 |
| 战斗页 | 四选一 | 〔规划 M4〕 | —(禁用返回) |
| 贸易页 | 交易列表(**门槛/缺货行跳过**) | 执行交易/全部卖出(弹确认) | 返回主页 |
| 事件对话框 | 选项列表 | 选择 | —(禁用,必须显式选择) |
| 确认对话框 | 确认执行/取消 | 执行/取消回原页 | — |
| 设置页 | 菜单 | 进入;重开本局 → 确认弹窗 | 返回主页 |

要点:
- **职业人数调节**:职业行按确定进入;此后 上/下=±1、长按上/下=±5,
  确定=完成退出。调节中长按确定也是"完成"。分配立即生效,每 10s 结算产出。
- **村庄页禁用长按返回**(按键组件长按会先发 PRESS,焦点在职业行时长按
  必先误触调节)——离页走"返回"行或页签。
- **危险操作确认**:设置·重开本局、贸易·全部卖出,确定/长按均打开
  确认弹窗(显示后果明细),确认执行/取消回原页。
- **战斗禁返回、事件禁返回**:防止误触破坏结算。

## 4. 荒野导航的体验优化

〔规划 M4〕合并移动、罗盘、路标、回程一键——见 GAMEPLAY.zh_CN.md §4。
当前实装:地图页列表式导航,东→废村、西→小屋两目的地可走。

## 5. 可发现性与教学(实装)

- 每页底部常驻说明行:村庄 = 分配操作或收入总览;建造 = 光标建筑的作用;
  主页 = 无(动作文字自解释)。
- 教学融在第一幕:生火(确定)→ 建造(列表+返回)→ 陷阱(手动收获)→
  陌生人事件(弹窗选择)。

## 6. 无障碍与容错

- 焦点双通道标识:金色文字 + 行首">"(位置+符号)。
- 主页日志:最新在上,最多 6 行(4 个动作行时 5 行),旧条目向背景渐隐。
- 〔规划〕按键音、无操作降背光/浅睡。

## 7. 不做的事(红线回顾)

- 不依赖电源键;不依赖组合键/双键同按(硬件不支持);
- 不做需要连点的玩法;不做限时反应玩法(按键延迟不可控);
- 不做"双击=左右"的默认方向映射(保留为隐藏实验开关,默认关闭);
- 村庄页不做长按返回(长按必先误触调节,见 §3)。
