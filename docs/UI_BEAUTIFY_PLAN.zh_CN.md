## 2. 设计原则

1. **三层模型**:结构线(边框/分隔/面板)做骨架、场景色(每页一个 accent)做身份、语义色(HP/资源/战报)做状态——对标业界文字游戏的共识做法。
2. **金色仍是全屏最亮**:所有新增 accent 色均比 `COL_GOLD` 暗哑,焦点层级不被稀释;每页同时亮色 ≤3 处(标题 accent / 焦点 / 一个语义状态)。
3. **T1-T5 零新字形**:只用 f12 闭集内已有符号(`─ · × → ≡`);T6 才评估新增(仅进 f12,f24 冻结不动)。
4. **兼容既有架构**:只改样式属性与少量新预建对象,不动绝对坐标全量重写模型,不触碰滚动/WRAP 禁令。
5. **mockup 先行**:每项先改 `tools/mockup.html`(1:1 孪生,迭代最便宜;注:mockup 尚未同步上游图例/纹样,改版时一并补)→ sim 截图+像素断言 → idf.py 编译尺寸检查 → 真机烧录+lvpool 心跳目检。
6. **两条上游红线**:提示行是 toast 瞬态通道,美化不碰其常态样式;新增标签固定高度 ≥14(f12 行高,I30)。

3. **事件弹窗选项按钮化**:`s_dacts` 行常态加 1px `COL_BORDER` 描边圆角块,焦点反色(3.2),不可付灰字+描边(3.2 事件行规则)——M6 后事件页高频出现,抉择重量感值回成本。
4. **设置页危险项**:"重开"行 t 列恒 `COL_ENEMY`(焦点反色时墨字,同全局规则);其上方间隙加全宽 `COL_RULE` 分隔线,与普通项隔开。

### 3.7 可选评估项(T6,默认不做,逐项独立决策)

| 项 | 成本 | 采纳条件 |
|---|---|---|
| 图标字形若干(▶ ◀ ▲ ▼ ● ◆ ♥ ★ 等,仅进 f12) | **每符号 ~150B**(字库瘦身后),8 个 ≈1.2KB + font_audit 分套校验;f24 冻结不涉及 | T1-T5 落地后仍觉"资源格/战报缺锚点"时 |
| 标题页 I1 星尘/木纹底纹 | 9.6KB(240×320 单色);**lv_image 管线已存在**(纹样先例),无需新建机制 | 火光带效果不足且真机渲染耗时 <50ms 实测通过 |

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 60ms 渲染吞键窗被放大 | 全计划无常驻动画;打字机仅开机 1 次 6 拍;T6 淡入真机实测后才采纳 |
| **LVGL 池余量(I30 红线)** | 新增 11 对象逐批真机启动+12 页遍历,记录串口 lvpool 心跳前后值;**模拟器不复现内存缺陷,真机是唯一裁判**;不足再议池扩容(96→128KB,让系统堆,先实测) |
| **新标签高度 < 行高触发布局死循环(I30)** | 一律走带钳制的 `label_new`(:252),不手写 `lv_label_create`;新增标签 h≥14 |
| 墨字压冷却暗条对比度不足 | 3.2 规则:冷却可见的焦点行用金描边而非金底,结构上规避 |
| 新文案/新符号引入闭集外字符(I31 ± 教训) | T1-T5 零新字形;任何文案改动照旧重跑 `gen_fonts.sh` + `font_audit.py`(分套口径),符号先过审计再上机 |
| 反色后焦点行与金色页签争亮 | accent 全部暗于 COL_GOLD(3.1 推导规则);验收含"每页亮色 ≤3 处"目检 |
| toast 与像素断言互相污染 | 断言前静置 >2s 或重进页面再采样;断言不含提示行色值(该行是瞬态通道) |
| mockup 与固件漂移 | 每批先 mockup.html 定稿截图后固件;mockup 先补上游已落地的图例/纹样差异 |

## 7. 明确不做

- 整屏 RGB565 位图背景(单张 150KB 仍偏大,且压垮统一暗色基调;I1 纹理走 T6 评估)
- 常驻动画(火把闪烁/光标呼吸——吞键窗随渲染频率倍增)
- LVGL 原生滚动 / `LV_LABEL_LONG_WRAP` / flex 布局重构(架构禁令,UI_FIX_PLAN §5 延续)
- 列表页组头(空间核算放不下,见 3.6)
- 提示行常态样式改动(toast 瞬态通道,见 §2 原则 6)
- 远征 水/食 阈值变色(上游 warned 红格已覆盖语义,再加色颜色拥挤)
- T1-T5 范围内新增任何字库字形(f24 标题闭集冻结;T6 仅议 f12)
