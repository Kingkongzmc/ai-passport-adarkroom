## 1. 总览

- 类型:菜单式文字放置冒险(参考 A Dark Room,内容量对齐)。
- 一局:约 8~15 小时(含挂机),通关后可继承开启新周目。
- 核心循环:**收集 → 建造 → 自动化 → 远征 → 剧情 → 终局**。
- 死亡规则:远征中水/食耗尽或战败 → 昏迷,被拖回小屋,损失携带物资的一小半,
  小屋资产不受损(没有"游戏结束",失败只罚进度,不删存档——放置游戏铁律)。

## 2. 第一幕:小黑屋(约 20~30 分钟)

| 阶段 | 内容 | 数值要点 |
| --- | --- | --- |
| 开场 | 黑屏,只有一行"屋里冷得刺骨",按钮区仅一个【生火】 | 火焰 5 档:熄灭/微弱/跳动/旺盛/炽烈(对齐原版 FireEnum);点火 5 木→旺盛,添柴 1 木 +1 封顶;点火/添柴共用 10s 冷却;每 300s 降一档 |
| 收集 | 解锁【收集木材】(冷却 10s,前期主要手动操作) | 每 10s +10 木(原版 60s/+50,节奏压缩) |
| 陷阱 | 建陷阱(需板车,可叠)后每 30s 可【查看陷阱】:单掷 50%,得毛皮/肉/诱饵;火熄时概率减半 | 首个"自动化"体验,教学离线结算;诱饵语义(消耗加掷 vs 奖励)M3 定案 |
| 陌生人 | 剧情事件:神秘女子到来,帮忙看火,逐步给提示 | 剧情标记驱动,不可跳过(已实装) |
| 建造 | 小屋(每间+2 人口)→ 更多流浪者定居(自然到达 M3 接入) | 人口 = 后续一切产能的上限 |
| 幕终 | 人口 ≥ 5、建好背包 → 解锁【出发:干燥的路】 | 进入第二幕 |

设计目标:30 分钟内让玩家经历"手动→自动→扩张"一次完整小循环,
并在第一次合盖离线回来看到陷阱收获,建立挂机认知。

## 3. 第二幕:村庄(数小时,与三幕交织)

- **村民职业**:伐木工/猎人/制革匠/采集者/铁匠/矿工等 10+ 种;
  每人每 10s 产出并消耗口粮;食物不足则罢工,不死亡。
  已实装:伐木工 +2 木、猎人 +1 毛 +1 肉(需猎人小屋)、采集者(未分配人口)自动 +1 木;
  分配交互 = 确定进入调节,上/下 ±1、长按 ±5。
- **建筑全量**(30+):工作场所解锁对应职业;仓库扩容;医院治疗远征伤;
  军械库解锁武器制造链(铁→钢→步枪)。
- **贸易站**:神秘商队定期到访(事件触发),用富余资源换稀缺资源,
  价格随幕数浮动;长按确定 = 整类全部卖出。
- **奇观线**(原作 Spaceship 前置):中期开始出现异星金属碎片线索。

## 4. 第三幕:荒野之路(游戏主体)

### 4.1 远征准备

- 背包容量(格子数)由建筑升级;水/食/武器/工具占格。
- 每移动 1 格耗 1 水 1 食(原作口径);带多少、留多少回程 = 核心决策。

### 4.2 世界地图(31×31)

- 中心为小屋;固定地点(城镇 A/B、前哨、异星残骸)+ 随机散布的
  废墟/村庄/洞穴(每局随机种子生成,种入存档保证复现)。
- 地形带:离小屋越远,敌人越强、战利品越好;四个角为极端危险区。
- 探索:列表式导航(方位·名称·距离),走过的格子点亮 9×9 小地图视野。

### 4.3 地点内部(房间网格)

- 每地点 3×3~5×5 房间,逐房【搜索】;可能:得物资 / 遭遇 / 陷阱 / 剧情标记 / 空。
- 守卫敌人(强于荒野杂兵);清空守卫后房间标记安全。
- 异星残骸:固定 4 层,越深越危险,是终局材料主产地。

### 4.4 战斗(回合制,四选一菜单)

```
敌 巨鼠 ▓▓▓▓░░ HP 66%
我 ▓▓▓▓▓░ HP 83%   水8 食6
> 攻击(铁剑 4-7)   ← 上/下选,确定执行
  武器/补给
  逃跑(70%)
```

- 公式按原作:命中率、武器伤害区间、敌人攻防表全量移植。
- 补给 = 战斗中喝水/进食回 HP;逃跑失败挨一下。
- 战斗动画 = 数字滚动 + 血条变化(2 帧足够,不追求华丽)。

## 5. 第四幕:终局与继承

- 收集齐异星金属 → 建造飞船(多阶段工程,消耗大量资源,村庄全速供养)。
- 剧情收束:神秘学说的真相、陌生人的身份、世界为何荒芜。
- 结局:起飞(结局卡)→ 可选择"继续留在这个世界"或"新周目"。
- 新周目继承:部分科技蓝图 + 悟性加成,门槛/底量按 ×1000^周目 扩展(参考 GitRich BALANCE 口径)。

## 6. 数值框架(总则)

- 全局心跳 1s(LVGL timer),产出/消耗按 10s 一个"经济 tick"结算,
  离线按 Δt 一次性补算(封顶 8h,系数 1.0;超封顶部分按 25% 折算,防挂机农场)。
- 一切产出进"累计获得"口径,消费永不降低收益类系数(转生类通行规则)。
- 数值表与代码分离(`dr_data.c` 纯 const 表),主机测试逐表校验
  (产出≥消耗不破产、建筑回本时间单调递增、幕间难度曲线平滑)。

## 7. 剧情/事件清单口径

- 50~70 个事件,分四类:主线(幕推进)、奇遇(远征随机)、日常(村庄)、隐藏(神秘学说线)。
- 每个事件 = 标题 + 1~4 段文本 + 2~4 选项 + 效果(资源/标记/对话框链)。
- 触发条件组合:资源门槛 / 建筑存在 / 剧情标记 / 概率 / 冷却。
- 文案全部重写:保留事件的功能与信息量,措辞原创、贴合废土中文语感。
