# UI 修复计划（2026-09-30 全界面分析）

> 跟踪方式：每项完成后把 `- [ ]` 改为 `- [x]`，并在"进度日志"追加一行。
> 实施顺序：批次 A → B → C，每批独立可验证、可暂停。

## 0. 背景与依据

- **截图证据**：33 张界面截图存于 `docs/screenshots/sim-audit-20260930/`
  - 新档 11 张（`01-`~`11-`）、满资源 12 张（`满01-`~`满12-`）、子状态 10 张（`补01-`~`补10-`）
  - 满资源档由一次性造档工具生成（木头 123456、毛皮 99999、全建筑、45 村民、全旗标）
- **字库实测**（`assets/fonts/dr_font_*.c`，NotoSansSC 比例字体）：
  - f12：数字 6.69px、汉字 12px、空格 2.69px、省略号 12px、斜杠 4.69px
  - f16：数字 8.88px、汉字 16px
- **布局基准**：内容区 198×278 @ 绝对(21,21)，内容区底 = 278（绝对 299）；屏幕 240×320 圆角 30px
- **玩法轨迹**：480 帧按键重放（调试副本模拟器，项目源码未动），产出真实远征/战斗/地点页截图
- 关键结论：`LV_LABEL_LONG_DOT` 截断阈值由 46px 资源格与比例字宽共同决定，**5 位数起必截断**

- LVGL 原生滚动/WRAP（架构硬禁令：全显式坐标 + 禁容器滚动 + 真机隐藏对象卡死渲染事故）
- 新增字库字形（k/M/袋/承/器/武/护/甲 等全部已在闭集字库内）
- M4 远征玩法与页签解锁本身（另行处理）
- mockup 未实现的"2 格距离"等细节
