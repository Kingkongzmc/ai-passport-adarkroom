# 玩法规格 — 《小黑屋》(忠实原版口径)

> 数值与机制的唯一事实来源是 [DESIGN.zh_CN.md §9「原版机制全量分析」](../DESIGN.zh_CN.md)
> (源码取证)。本文件是面向实现/测试的玩法口径摘要;**本作不新增原版
> 没有的玩法**,偏离仅限设备适配三项(三键 UI/NVS 存档/离线补算)。

## 0. 开局

新档木材 15,其余为 0。唯一可做的是【点火】(5 木 → 旺盛)。火焰首次
达到"跳动"后,一个陌生人踉跄入场倒下;约 15s 后"柴火快烧完了"——木材
被直接置为 4,森林(村庄页)开启,采集木材成为木材来源。

## 1. 第一幕:小屋(原版 Room)

- **火焰**:5 档(熄/微/跳/旺/炽)。点火 5 木直达"旺盛";添柴 1 木 +1 档;
  共用 10s 冷却;每 300s 降一档。降档时若"陌生人已恢复 && 火焰 ≤跳动 &&
  有木",她先添 1 木(火不落到跳动以下)。
- **室温**:5 档(冻结/冷/微温/暖/热),每 30s 向火焰档靠拢一步;
  室温 ≥"暖"是陌生人恢复的条件;室温 >"冷"才能施工。
- **陌生人(建造者)**:晕倒 → 发抖 → 沉睡 → 帮忙,每态 30s 且需室温 ≥暖。
  恢复后:+2 木/10s,降档自动添柴,**建造菜单解锁**。
- **建造**(小屋页):造价/上限见 §3;可见性 = 陌生人已恢复 && 木材过半 &&
  造价材料见过。

## 2. 第二幕:村庄(原版 Outside)

- **采集木材**:60s 冷却,+10 木;板车后 +50。
- **陷阱**:可叠 10 个(10+10n 木);**每 90s 查看一次**,每个陷阱必得 1 件,
  掉落六档:毛 50% / 肉 25% / 鳞 10% / 牙 8% / 布 6.5% / 护符 0.5%;
  有饵时掉落件数 = 陷阱数 + min(饵, 陷阱数),饵自动消耗(捕兽人产饵)。
- **人口**:小屋 ×4 人/屋(上限 20 屋);建房不加人口;流浪者每 0.5~3 分钟
  成批到达(人数 = 随机(余量/2)+余量/2,至少 1)。**村民没有口粮消耗**,
  不会饥饿——人口只被事件削减(M6 内容)。
- **职业**(每 10s/人,原料不足当 tick 空转):

| 职业 | 产消 | 解锁 |
| --- | --- | --- |
| 采集者(未分配) | +1 木 | — |
| 猎人 | +0.5 毛 +0.5 肉 | 猎人小屋 |
| 捕兽人 | −1 肉 → +1 饵 | 猎人小屋 |
| 制革匠 | −5 毛 → +1 革 | 制革坊 |
| 熏肉匠 | −5 肉 −5 木 → +1 干肉 | 熏肉房 |

(矿工/炼钢/军械归 M4。干肉是远征口粮,不是村民食物。)

## 3. 建筑造价(原版 Craftables)

陷阱 10+10n(max10)/板车 30/小屋 100+50n(max20,每屋+4人)/猎人小屋
200木+10毛+5肉/贸易站 400木+100毛/制革坊 500木+50毛/熏肉房 600木+50肉;
工坊 800木+100革+10鳞、炼钢厂、军械库随 M4。

## 4. 贸易(原版:只买不卖)

贸易站建成后,游牧商人以毛/鳞/牙易货:鳞 150 毛;牙 300 毛;铁 150毛+50鳞;
煤 200毛+50牙;钢 300毛+50鳞+50牙;子弹 10 鳞;罗盘 400毛+20鳞+10牙(限1)。
**没有卖出通道**——木材只来自采集与采集者。

## 5. 第三/四幕(M4+:荒野与远征)

61×61 世界(视野 15×15);干肉每 2 步 1 口、水每 1 步 1 口;工坊制造
武器/护甲/水具;战斗回合制;危险:寒夜、野兽袭村。详见 DESIGN §9.7/9.8,
数值表动工前先出(M4 前置)。

## 6. 存档与离线(设备适配)

- NVS 全量打包 + CRC + 版本迁移(当前 v3;v1/v2 布局冻结,按实际长度验
  CRC 后逐版本迁移,app-only 烧录升级不丢档)。
- 动作即存 + 每 60s 周期存档;主页日志环形缓冲独立键随档持久化。
- 离线补算:按同一收入表逐 tick 补算(8h 全速封顶,超出 25% 折算);
  火焰离线即熄;陷阱按 90s 周期补掷(不耗饵)。
- 整片镜像(-full.bin @0x0)会清档:发布同时给 full.bin + app.bin 两个
  产物,升级说明写明"老玩家用 app.bin"。
